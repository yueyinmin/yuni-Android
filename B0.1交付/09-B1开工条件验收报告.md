## 7. B1 交接材料

### 7.1 B1 当前工程基线
- Commit `b7f6d04`，本地 main 分支，单模块 Kotlin/Compose 工程。
- Room v2 + 迁移测试；21 个单测全绿；Debug / Release 构建通过。
- `AppConfig.cloudEnabled` 当前为 false（envId 为空），App 走本地离线实现，0 网络请求。

### 7.2 B1 预计修改范围
- `data/remote/cloudbase/CloudBaseAuthDataSource`、`CloudBaseCoupleRemoteDataSource`：注册/登录/邀请码/核销。
- `data/repository/impl/RepositoryImpls.kt` 的 `AuthRepositoryImpl`、`CoupleRepositoryImpl`。
- `domain/repository/Repositories.kt` 对应接口（如需扩展）。
- 新增 B1 页面：登录/注册、邀请码、空间绑定（当前工程还没有，本轮禁止提前写）。
- 云端：PG 表 RLS 策略、`couple.issueInvite` / `couple.redeem` 云函数。

### 7.3 B1 数据模型依赖
- 依赖 v2 的 `coupleId` 字段；`couple_profile` 表已有。
- 依赖 `TokenVault`（Keystore 加密）保存登录态。
- 依赖 `CloudSessionState.coupleId` 在登录/取空间后正确赋值。
- 不依赖 B2～B7 的表。

### 7.4 B1 云端依赖
- 1 个免费体验环境（需用户授权创建）。
- PostgreSQL 模式：PostgREST + JWT + RLS。
- 身份认证：用户名密码（免费版支持基础登录能力）。
- 2 个云函数：邀请码签发与核销；3 秒超时 / 256M 限制内实现。
- **不依赖**实时推送、厂商推送、自定义域名、数据回档（免费版没有）。

### 7.5 B1 权限要求
- 服务端：`auth.uid()` 取值，忽略客户端传的 userId；RLS `is_couple_member(couple_id)`；邀请码云函数原子核销。
- 客户端：登录后写 TokenVault；退出登录只清登录态，不清本地日记；coupleId 为空时不允许上传共享数据。
- 对应 06 号规范的攻击面 1、2、3、8。

### 7.6 B1 验收标准
1. 注册 / 登录 / 退出登录成功，Token 不明文落盘。
2. 邀请码只能核销一次；第二个人核销后空间 `memberBId` 有值。
3. 跨空间访问返回空结果或 403（服务端实测，不是客户端模拟）。
4. 伪造 userId / coupleId 不能读写他人数据。
5. 退出登录后本地日记、回忆一条不少。
6. 免费环境开关状态有截图证据；没有自动续费、没有按量付费。
7. B1 相关单测与仪器测试通过；构建成功。

### 7.7 B1 已知风险
- 免费版云函数 3 秒 / 256M，邀请码逻辑必须轻。
- 免费额度 3,000 点/月（≈3 元），按量实测前不要承诺"够用"。
- 6 个月到期需手动续；活动续期截止 2026-12-30。
- 实时推送能力降级（未读中心 + 打开同步）。
- Room 历史 NULL coupleId 数据需明确归属规则后才能参与共享。
