### 测试实现说明

- 迁移测试没有用官方 `MigrationTestHelper`（AGP 8.7 不把 `test.assets` 合并进单测资源）。改为读 `app/schemas/.../1.json` 的 `createSql` 自建真 v1 库，再用 Room(v2) 打开，**由 Room 自己执行迁移并做 `validateMigration`**。schema 正确性由 Room 判定，测试只断言数据。
- 测试用 `@Config(sdk = [33], application = android.app.Application::class)`，避开 `YuniApplication.onCreate` 里的 WorkManager 初始化（Robolectric 下 AndroidX Startup 不执行）。
- OutboxWriter 测试用内存假 DAO，验证的是"闸门是否放行"，不是 SQL 正确性。

### 测试过程中真实修复过的问题（留痕）
1. `IllegalStateException at WorkManagerImpl.java:158` → 指定空 Application。
2. `FileNotFoundException: Missing file .../1.json` → 自建 v1 库，不依赖 test assets。
3. `NOT NULL constraint failed: daily_question.revealed` → v1 INSERT 显式给 `revealed = 0`。
4. 测试暴露 Outbox 真 bug：每次新 UUID 导致 `insertOrReplace` 覆盖不了旧任务 → 复用旧 taskId。
